### Вариант 4: Матричный шифр (Перестановочный)
Метод: запись текста в матрицу по строкам, чтение по столбцам.
Задача: реализовать MatrixEncrypt(string text, int rows, int cols).
Требования:
- автодополнение пробелами до заполнения матрицы;
- валидация размеров матрицы.
Тестирование:
- проверка разных размеров матриц;
- восстановление текста с пробелами;
- неполные матрицы.

### Выводы по итогам комплексного тестирования

### Применяемые виды тестирования

- **Функциональное тестирование** – проверка пользовательских сценариев (шифрование, дешифрование, очистка).
- **Тестирование безопасности** – валидация ввода, защита от некорректных данных.
- **Тестирование UI** – проверка подсказок, активности кнопок, ввода только чисел.

### Применяемые техники тестирования

- **UML-диаграмма вариантов использования (Use Case)** – визуализация требований к системе.
- **Классы эквивалентности** – разделение данных на валидные и невалидные.
- **Анализ граничных значений** – проверка rows=0, rows=1, отрицательные значения.
- **TDD** – тесты написаны до реализации кода.
